Kanban Board is a real-time, multi-user task board: create boards, organize work into columns and cards, and collaborate live with the people you invite. Built on Next.js, React, TypeScript, and Firebase.

It's built with two equally load-bearing goals:

<CardGroup cols={2}>
  <Card title="Genuinely useful" icon="users">
    A shared task board for real collaborators — friends, roommates, small project teams — usable without onboarding friction.
  </Card>
  <Card title="A portfolio piece" icon="sparkles">
    Demonstrates production-grade engineering judgment: concurrency correctness, derived vs. current state, and deliberate use of external APIs.
  </Card>
</CardGroup>

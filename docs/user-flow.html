🧭 Kanban board — reference

User flow

How someone actually moves through the app — from first landing on it or an invite email, to the day-to-day loop of using a shared board. Product/UX view, not the backend architecture (see the companion architecture diagram for that).

Flow · getting onto a board

Onboarding, sign-in, and invites

Two ways in: someone arrives cold and signs up themselves, or someone arrives via an invite email and is dropped straight onto the board they were invited to — whether or not they already had an account. 

flowchart TD
  Start(["Visit the app"]) --> HasInvite{"Arrived via an invite link?"}

  HasInvite -- "No" --> AuthCheck{"Already signed in?"}
  AuthCheck -- "No" --> Login["Sign up or log in"] --> Dashboard["Boards dashboard"]
  AuthCheck -- "Yes" --> Dashboard

  HasInvite -- "Yes" --> InviteAuthCheck{"Already signed in?"}
  InviteAuthCheck -- "No — new user" --> Signup["Sign up, pre-filled from the invite"] --> JoinBoard["Added as a board member automatically"]
  InviteAuthCheck -- "Yes — existing user" --> JoinBoard
  JoinBoard --> BoardView["Lands directly on the shared board"]

  Dashboard --> CreateOrOpen{"Create a new board, or open one?"}
  CreateOrOpen -- "Create" --> NameBoard["Name it, add starting columns"] --> BoardView
  CreateOrOpen -- "Open existing" --> BoardView
Flow · using a board

The day-to-day loop

Once on a board, everything radiates out from the same screen — every action either updates the board directly or opens a small, focused step that returns you right back to it.

user action returns to board view 
flowchart TD
  BoardView(["Board view — columns & cards"])

  BoardView --> Drag["Drag a card to a new column or position"]
  Drag --> Sync["Update appears instantly for every collaborator"]
  Sync -.-> BoardView

  BoardView --> OpenCard["Open a card"]
  OpenCard --> CardDetail["Edit title, description, assignee, due date"]
  CardDetail -.-> BoardView

  BoardView --> Feed["Open the activity feed"]
  Feed --> SeeUpdates["See what collaborators changed recently"]
  SeeUpdates -.-> BoardView

  BoardView --> Invite["Invite a collaborator"]
  Invite --> EnterEmail["Enter their email address"]
  EnterEmail --> EmailSent["They receive an email — join link or 'shared with you'"]
  EmailSent -.-> BoardView

  BoardView --> Background["Change the board background"]
  Background --> SearchUnsplash["Search Unsplash, pick a photo"]
  SearchUnsplash -.-> BoardView

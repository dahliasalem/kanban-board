🖼️ Kanban board — reference

UI wireframes

Low-fidelity layout for the core screens, using the "Iceland Trip" board as a running example so the structure is grounded in real content rather than placeholders. Visual design (color, type, spacing) is intentionally undecided here — this is about screens, hierarchy, and where each PRD feature lives.

Screen · app shell

Sidebar + board view

A persistent left sidebar replaces a standalone dashboard page — every board the user belongs to is one click away, "+ Create new board" lives right at the top of that list, and the active board is highlighted. In the top bar, "Invite" and "Background" are tucked under a ⋮ overflow menu (shown open here) rather than sitting as separate buttons, leaving only "Activity" — the one toggle used often enough to earn its own spot — visible by default. Below, the board's default state: the activity feed itself is hidden until toggled open.
